# py_taskhub
In the application:

Each team member can:

-create new tasks,

-assign them to other users,

-set deadlines,

-mark tasks as completed.

The database is designed according to the provided schema, which includes relationships between users, tasks, statuses, and priorities.(https://media.mate.academy/It_Company_Task_Manager_a8510d162c.png)

The system helps monitor task progress and prevents chaos within the team.

It is a practical solution for team collaboration in an IT environment.
