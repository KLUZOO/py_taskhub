## 📝 Project Description (English)

### Main Page

On the main page, anyone can view the list of tasks, including their:

- status,
- description,
- deadline,
- number of assigned workers,
- priority.

Only registered workers can add new tasks.

You can also see:

- total number of site visits,
- number of registered workers,
- number of created tasks.

### Task Detail Page

Clicking on a task opens its detailed page. Registered and assigned workers can:

- edit the task,
- delete it,
- mark it as completed.

### Workers Page

Displays all registered workers. Each worker can edit or delete only their own account.

### Task Type and Position Pages

Registered workers can create and edit task types and job positions on the respective **Task Type** and **Position**
pages.

### Authentication and Account Access

Users can:

- register,
- log in,
- log out,
- access their account information from any page.

### Search and Pagination

Search functionality is available on:

- the main page,
- the workers page,
- the Task Type and Position pages.

Pagination is implemented to make navigation easier when many items are present.

## 📝 Опис проєкту (українською)

### Головна сторінка

На головній сторінці будь-хто може переглядати список завдань, включно з їх статусом, описом, дедлайном, кількістю
призначених працівників та пріоритетом. Лише зареєстровані працівники мають можливість додавати нові завдання.

Також відображається:

- загальна кількість візитів на сайт,
- кількість зареєстрованих працівників,
- кількість створених завдань.

### Детальна сторінка завдання

Натиснувши на завдання, відкривається його детальна сторінка. Зареєстровані та призначені працівники можуть:

- редагувати завдання,
- видаляти його,
- позначати як виконане.

### Сторінка працівників

На цій сторінці можна переглядати всіх зареєстрованих працівників. Кожен працівник може редагувати або видаляти лише
свій акаунт.

### Task Type та Position

Зареєстровані працівники можуть створювати та редагувати типи завдань і позиції відповідно на сторінках **Task Type** і
**Position**.

### Аутентифікація та доступ до акаунта

Користувач може:

- зареєструватися,
- увійти в акаунт,
- вийти з нього,
- переглядати інформацію про власний акаунт на будь-якій сторінці.

### Пошук і пагінація

Пошук реалізовано на:

- головній сторінці,
- сторінці працівників,
- сторінках Task Type і Position.

Пагінація доступна на всіх відповідних сторінках для зручної навігації.
